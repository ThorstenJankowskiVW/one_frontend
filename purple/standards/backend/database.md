# Datenbank

## DOs
- DO behandle Datenbankthemen als ausserhalb des Scopes dieses Frontend-Demonstrators.
- DO modelliere persistente Informationen als Demo-Daten oder Externsystem-Kontext, solange kein echtes Backend eingefuehrt wird.
- DO dokumentiere Herkunft und Aufbereitung externer Demo-Datensaetze, zum Beispiel aus Kaggle, wenn sie in die Demo uebernommen werden.
- DO dokumentiere jede kuenftige Persistenzgrenze, bevor Frontend-Annahmen darum gebaut werden.

## DON'Ts
- Diesem Repo keine lokalen Datenbankschichten, Migrations-Workflows oder Pseudo-Persistenzabstraktionen hinzufuegen.
- Statische Demo-Daten nicht so praesentieren, als waeren sie durch eine echte Source of Record abgesichert.
