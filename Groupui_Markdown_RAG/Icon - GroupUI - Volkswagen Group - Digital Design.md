# Icon

---

## Usage
Icons are essential elements of a product interface. They communicate meaning where text doesn’t fit, represent an action, or draw attention to other UI elements. Volkswagen Group icons stand for simple, seamless, and progressive movement - this is represented by the flow of the lines and gaps of the icons.
While each icon is visually distinct, all product icons follow the same guidelines to ensure a consistent appearance across all digital products. When designing new icons, always focus on representing the meaning in the most basic way and prioritize function over how nice the icon looks. Icons serve a specific purpose in an interface, they are not illustrations.
GroupUI offers a large number of icons for a wide range of use cases. Before you create a new icon, check our icon library to see if the icon already exists.
Read more about the Volkswagen Group Iconography on the [Volkswagen Group Brand portal](https://volkswagen-group.frontify.com/document/1636#/design-elements/iconography).
For your information: As you might have noticed, the new corporate design includes slightly upgraded icon guidelines. We are currently reworking our guidelines and the icon library.
We'll provide the updated icons as soon as possible.

## Anatomy
All icons follow the same guidelines to provide a coherent experience across all interfaces. Weight, fill, grade, and optical size follow the same patterns, icons are build based on the same key shapes, and are designed on the same icon grid.

---

### Sizes
We offer all icons in four different sizes. All icons have a 1px stroke width, no matter which size.
| Token | Icon size |
| --- | --- |
| icon-size.s | 16 × 16 px |
| icon-size.m | 24 × 24 px |
| icon-size.l | 32 × 32 px |
| icon-size.xl | 48 × 48 px |

---

### Outlined and filled
Use outlined icons to help users recognize and select available actions in your interface.​ Use filled icons for highlighting selected states or for areas that require a little more weight and readability.

---

### Color
To improve the user experience, icons are color-matched to their surrounding context, such as interactive elements, text, or highlighting, using the defined colors to weight content and better guide the user.

---

### Base grid
The grid is the foundation of every icon. It provides guidance to maintain visual consistency and proportions across the icon set and helps ensure that an icon is as usable as possible by as many people as possible.
Base grid

---

### Artboard
Icons are placed inside the content area, which is surrounded by a safe area, varying for different icon sizes.
Artboard
Important
Do not resize these areas or place elements outside the content area. Please use the grid templates provided to create additional icons.

## Style
Our icon style is designed to help create clear, easy-to-understand icons with a consistent appearance. With our icon style, we can create high-quality, consistent, and recognizable icons that contribute to a strong and memorable brand identity.

---

### Oneliner
The Volkswagen Group icons are designed using a continuous line, whenever possible. This style prioritizes simplicity and elegance by minimizing the number of lines used in each icon and visualizes the idea of continuous movement.
Note
When designing new icons be mindful - a continuous line will not work for every icon and should only be designed this way, if it doesn’t interfere with the icon’s meaning.

---

### Strokes
All icons are made of strokes. To keep them consistently sharp and crisp all icons use a 1 px stroke width. This width is used on all instances of an icon, including curves and angles.
Stroke width (Icon Size M)
### End caps
All strokes of the icon system end in a basic square shape.
Squared end caps (Icon Size M)

---

### Corner radius
An icon’s lines have curved corners. Icons can use a larger corner radius or a smaller one. The recommended corner radius values are between 2 and 4 (for 24px icon).
|  | Icon size S | Icon size M | Icon size L | Icon size XL |
| --- | --- | --- | --- | --- |
| Radius S | 1 px | 2 px | 3 px | 4 px |
| Radius L | 4 px | 6 px | 8 px | 10 px |
Corner radius (Icon Size M)

---

### Distances
The distance between strokes and elements scales depending on the size of the icon. This guarantees a consistent appearance and increases readability.
| Icon size S | Icon size M | Icon size L | Icon size XL |
| --- | --- | --- | --- |
| 1 px | 2 px | 3 px | 4 px |
Distance of strokes and elements (Icon Size M)
Exception
﻿In special cases, when the meaning of an icon is endangered the distance can be reduced to 1 px.

---

### Line breaks
The break in the line is characteristic of the overall look and feel of icons in the Volkswagen Group identity. They vary for each icon size. We recommend using smaller breaks in smaller icon sizes. To ensure the icon's readability, place breaks in areas that do not disrupt the overall shape.
**Special feature – Similarity:**
If similar shapes are placed next to each other, one of them needs to have an interruption.
**Special feature – Overlap:**
If one of the overlapping shapes is a circle, one quarter needs to be removed.
| Icon size S | Icon size M | Icon size L | Icon size XL |
| --- | --- | --- | --- |
| 1 px | 2 px | 3 px | 4 px |
Line breaks (Icon Size M)

### Icon sources
By default the icon component loads the icons directly from a CDN.
But it also provides two more possibility to specify an icon source.
The first one is `icon-source`, which needs to be defined on the body tag. Here you could define a local folder in the case your environment prevents the icon component from accessing the CDN.
The second one is the `src` property of the icon component. Here you have to define the whole icon path including the icon name.
See the examples below.
For testing purposes with the `icon-source` on the body you can also add the following code snippet to your setup.
document.body.setAttribute('icon-source', '/assets/icons');
document.body.setAttribute('data-gui-brand', 'vwgroup');
Attention:
﻿Changing the icon source only applies to the web components. In the CSS Icon component there currently is nothing to change that.

### g-icon
To add an icon to your page, use an <i> tag and add the classes g-icon and g-icon-{icon-name}-{icon-size}.
﻿If you are using the icon within your component (e.g. g-btn), and additional css class may be needed (e.g. g-btn-icon). Please check the documentation of the used component for more information.

### custom icons
To change an icons source you can apply the style attribute —g-icon-url to use custom paths and/or own icons.
