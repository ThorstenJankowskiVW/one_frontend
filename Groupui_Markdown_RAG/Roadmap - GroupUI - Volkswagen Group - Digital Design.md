# Roadmap

---

## Introduction
The Roadmap for the Volkswagen Group design system contains the strategic planning and milestones as well as general goals that we pursue. The planning in design and development is created within our balanced team based on user feedback and should give an overview of topics we plan to develop next on the epic level. The Roadmap for the quarters did not contain any order in which the topics are processed.
We reserve the right to plan the topics within our iterations. For each quarter try to further develop our documentation as well as the reusable design and software components. The roadmap serves also as a rough guide and does not constitute a delivery commitment. It can be adapted according to new knowledge and requirements.
External requirements:
Our [contribution process](https://digitaldesign.volkswagen-group.com/r/1vW3UIWoQ6ZfMJkmuFtzNTN8onxCN0qrpbcWVDAE3eE) gives you the opportunity to share requirements and bugs with us. These are regularly reviewed and prioritized within our iterations based on our requirement engineering.

## Roadmap 2026 - Q2
**New Components & Features**
* **Anchor Navigation:** Enables smooth navigation between different content sections within a page.
* **Classification Label:** Introduces standardized labels to clearly classify applications and websites.
* **File Upload:** Allows users to upload data, files, or documents within forms and workflows.
* **Side Panel:** Provides a flexible side panel component required for secondary content.
* **Typography:** Defines consistent typography styles to ensure readability and visual coherence.
* **Card Design:** Develops a reusable and scalable layout system for card‑based content.
* **Figma Slots:** Enables slot functionality in Figma components to increase flexibility and reuse.
**Best Practices**
* **Navigation:** Defines guidelines for designing clear, scalable, and accessible navigation patterns.
* **Forms:** Shares recommendations for designing usable and consistent form experiences.
* **Empty States:** Provides guidance on empty states to support user orientation and action.
**CSS Components**
* **Table:** Delivers flexible and accessible table styles for structured data presentation.
* **Menu:** Provides a configurable CSS menu component optimized for prioritised use cases.
* **Navigation:** Defines consistent CSS navigation styles for common navigation patterns.
**AI within Design System**
* **AI‑Generated Skills.md:** Automatically generates and maintains skills documentation based on existing design system content.
