# Installation (JSON)

---

Since version **2.1.0**, we provide a JSON version of the GroupUI Design Tokens. They are available either as npm packages for local installation or directly served from our CDN. Currently, these are the installation options:
* Package from CDN using npm
* Package from the Devstack artifactory using npm
* JSON file served directly from GroupUI CDN
