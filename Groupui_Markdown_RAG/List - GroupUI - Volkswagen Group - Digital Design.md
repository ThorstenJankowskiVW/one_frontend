# List

---

## Usage
Lists present content in a way that makes it easy to scan and find information the user might be looking for.

---

### List - Live demo
```html
<div class="container-border flex-center">
<div class="list-live-demo-box">
<groupui-headline heading="h6">Ordered list</groupui-headline>
<groupui-list>
<ol>
<li>Item</li>
<li>Item
<ol>
<li>Item</li>
<li>Item</li>
</ol>
</li>
</ol>
</groupui-list>
</div>
<div class="list-live-demo-box">
<groupui-headline heading="h6">Unordered list</groupui-headline>
<groupui-list>
<ul>
<li>Item</li>
<li>Item
<ul>
<li>Item</li>
<li>Item</li>
</ul>
</li>
</ul>
</groupui-list>
</div>
</div>

```
