# Elevation

---

## Usage
The elevation is an important part of our design system to visually highlight content and areas on a page. In the Volkswagen Group design, all contents are displayed flat (elevation 0). Only for highlights (elevation 8) an elevation is used. The vertical stacking order of surfaces in the user interface is defined by the [Z-index](https://digitaldesign.volkswagen-group.com/r/vVAKjyJBSYTNoGhgz2aKega0iDcibkgFNGWyOAOUmiU).

---

### Elevation 8
Only to highlight certain components elevation is used. Elevation (shadow) indicates a hover state or that a component is raised higher above others. Don't overwhelm the user - limit the number of elevations and avoid nested elevations in page layouts.
**Components:**
* Tooltip
* Popover
* Modal
* Toast
* Interactive Cards in hover state
