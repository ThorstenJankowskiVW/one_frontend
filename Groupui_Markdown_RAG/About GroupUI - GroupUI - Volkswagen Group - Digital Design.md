# About GroupUI

---

The GroupUI toolchain includes a design system for modular user interfaces and a development framework for designing and developing applications within the Volkswagen group and its brands. It’s responsive to work on any modern device.
GroupUI enables designers and developers to build better web applications using a consistent design language that feels, looks and works the same way for every Volkswagen Group product.

---

### Fast & Efficient
The ability to build digital experiences from a range of existing components speeds up the product creation process. Designers are supported with a set of components and have less re-work to do through the usage of symbols. Developers can start to build with code that was previously created, tested, and implemented.
### Scale & Collaborate
A consistent design language simplifies the process of scaling digital products. Instead of adding incoherent design elements to products, all designers work with the same user interface library. Component changes can be easily made and transferred to other areas of the product with the same component.
### Group-Wide & Themeable
The GroupUI design system is a group-wide UX toolchain for modular user interfaces and a development framework for corporate applications. It enables designers and developers to build better products using a consistent design language that feels, looks and works the same way for every Volkswagen Group product on any given device.

---

## Flexibility
Flexibility is a very important part of our design system. Our goal is to continuously develop the design system and to guarantee flexibility in the design and in the web components.
In order to make the design system as flexible as possible, we depend on your feedback and your requirements. In further development, we try to take these into account as best as possible, but here too we do not have to disregard the holistic view and prioritization of the components.
#### We differentiate in these categories:
1. **No adjustments**The design or web components can be used in your product without further adjustments.
2. **Small adjustments**The design or web components can be adapted and used via the integrated property.
3. **New extensions**The design or web components are available and have to be extended by a property.
4. **New Component**The design or web components have not yet been implemented and have to be developed.
When expanding existing components or creating new components, we ask you as designers and developers to support us in the development.
In order to communicate all requirements transparently with the community, to create synergies between different teams and to integrate the requirements into our design system in the best possible way, we have developed a contribution process and ask you to share your requirements with us and the community.
Note:
We are only a small core team but try to support you in the best possible way with the implementation of existing components or create new components.
Nevertheless, you are always welcome to give feedback that we can continuously improve.

## Target groups
GroupUI takes a holistic, user-centered approach for which we have identified the following target groups.

---

### **Designer & Developer**
The designers and developers work with the design system on a daily basis and know the requirements of the users of the final product that will be built with the Volkswagen GroupUI. The designs and web components developed by the designers and developers are based on synchronized components and speak the exact same language. The harmonized design is part of every application and contribute to a uniform and good user experience in the product.

---

### User
Users of the final product which was built using Volkswagen GroupUI are the main target group when it comes to user experience. Our wide variety of user groups from employees to end users have to be involved in a user centric approach when creating application designs. The quality of the design system has got a direct impact on the user experience with the product.

---

### Business Stakeholders
Every Business Stakeholder should be interested in achieving fastet time to market from design to development at the most efficient cost. GroupUI is delivering fully CD-matched frontend components for every Brand and every touchpoint. If you are intested in reaching the most synergies, GroupUI is your choice for UI Design and Frontend Development.

---

### Generally
Anyone within the Volkswagen Group who is looking for a flexible, modular yet scaleable solution to build Applications or even Prototypes is welcome for a short introduction on our Design System.
