# Button group

---

## Usage
The Button Group component consists of several buttons which are directly connected to each other and can be used as an additional navigation component. There is also the option of using the component as a checkbox or radio button.

---

### Buttongroup - Live demo
```html
<div class="buttongroup-live-demo container-border flex-center">
<groupui-button-group>
<groupui-button-group-button>Button</groupui-button-group-button>
<groupui-button-group-button>Button</groupui-button-group-button>
<groupui-button-group-button>Button</groupui-button-group-button>
</groupui-button-group>
</div>

```

  Use similar button properties in the group.
* ![](./Button group - GroupUI - Volkswagen Group - Digital Design_files/eyJwYXRoIjoidm9sa3N3YWdlblwvZmlsZVwvc2prVHFMdnNhQ0IzR1FXM00zZlcucG5nIn0_volkswagen_0xz1UZznuUG1gD2z2YIC319CLvZXgJuyj7ff1tLYlCI)

  Use short and consistent button group labels.
* ![](./Button group - GroupUI - Volkswagen Group - Digital Design_files/eyJwYXRoIjoidm9sa3N3YWdlblwvZmlsZVwvRXBpSDlTd1dyNEVYWThBeWFXQjkucG5nIn0_volkswagen_h_ggPr2qg2lZ4pk9r9W9ZCm2_cR5dT5gkK7s9L061hY)
  Do
  Use button groups to select options, switch views, or sort elements (eg. list vs grid).
* ![](./Button group - GroupUI - Volkswagen Group - Digital Design_files/eyJwYXRoIjoidm9sa3N3YWdlblwvZmlsZVwvaDZub2dXR0xZeTJmR0x4Y2EybWgucG5nIn0_volkswagen_oE3xLC4Mf4cDMiRB1BDPlM0cMmnKhCtF1YJ09CLA-co)

  Do not mix button properties in the group.
* ![](./Button group - GroupUI - Volkswagen Group - Digital Design_files/eyJwYXRoIjoidm9sa3N3YWdlblwvZmlsZVwvdkZWdGhqQmNiQU16a25TQlJaUlQucG5nIn0_volkswagen_8FUFcHHoGKIwdvBHg00Nq-ERU0a_twXdI43TD9ji1Mo)

  Do not wrap button group labels to a second line.
