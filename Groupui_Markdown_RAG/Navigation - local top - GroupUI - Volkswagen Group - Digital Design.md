# Navigation - local top

---

## Usage
Local top navigation represents the second or third level pages of a site's structure. Only one instance of the local top navigation must be used per page.
**Use local top navigation when:**
• a global top or side navigation is already in place
• only 3-5 categories are required
[Navigation overview](https://digitaldesign.volkswagen-group.com/r/Yi-5jIRZ3yV8eOnDl-By1ZLYZml6ZTfUpTQM7HNBGFg)
Global navigation components with local top navigation

---

### Anatomy
Icon (optional)
Label
Active indicator
Sub-menu for additional navigation items when space is limited
Divider line

### Sizes
Local horizontal navigation comes in two sizes:
Large: Ideal for layouts needing more white space, such as marketing websites.
Small: Perfect for layouts requiring compact navigation to maximize content area, like data-rich pages.
Top - size large (L), bottom size small (S)

### Do
Do use the default colors of the top navigation.
### Don't
Do not customize the colors of the top navigation.
### Do
Do use the same top navigation item options eg. all text, all icon, all text and icon
### Don't
Do not mix top navigation item options eg. a mix of text and icons for different options.
To pick up a draggable item, press the space bar.
While dragging, use the arrow keys to move the item.
Press space again to drop the item in its new position, or press escape to cancel.
