# Component overview

---

## Overview
The following table contains an overview of all the components and basics which are already implemented in the CSS Framework.
| Component | Description |
| --- | --- |
| [Avatar](https://digitaldesign.volkswagen-group.com/r/mU2C74il8p_1um3b9aSQwxNiUA_N8qT_IivixSNZIE8) | Avatars are visual representations of a user, typically shown as a small image, initials or icon. |
| [Badge](https://digitaldesign.volkswagen-group.com/r/7-H-CzQXxBPOoJbyivIQRpJV0BwhUZ8ME0UlGen1n_c) | Badges are small elements used within buttons, links, or other elements to provide additional context or highlight important information. |
| [Banner](https://digitaldesign.volkswagen-group.com/r/IHe7i2phKTWUfMS9dixh65utciP3VDB_cGjCo6c_C8c) | Banners are prominent message areas used to display important information or alerts to users. |
| [Button](https://digitaldesign.volkswagen-group.com/r/wyNke0h6aJ8Gx3f7TeMuMdabG1uqvHRlwOJPtyDY_38) | Buttons are interactive elements that triggers an action when clicked or tapped. |
| [Cards](https://digitaldesign.volkswagen-group.com/r/IDwPmOS12VXlnvQXrqJHUBgjqj8Tu2HW-weJnz1jcW4) | Cards are flexible containers used to group related information, such as text, images, and actions, in a visually distinct way. |
| [Checkbox](https://digitaldesign.volkswagen-group.com/r/co-Sm7XaQlK8mkGHniZJfWG82eIqeYBnrfOmYTFuggo) | Checkboxes are interactive elements that allow users to select or deselect options. |
| [Chip](https://digitaldesign.volkswagen-group.com/r/PBn4pRsjeDEF9Z1YT1SX9LREYu-QW8qrIYohP_1R1Bw) | Chips are small, interactive elements used to represent input, attributes, or actions, often including text and an optional icon. |
| [Divider](https://digitaldesign.volkswagen-group.com/r/ycK-Egm-yWC0GhuPnh54QCHmKZVU_a1qYqZa3wvvm9Y) | Dividers are used to visually separate content sections, typically represented by a horizontal line, enhancing the layout and readability of a webpage |
| [Floating Action Button](https://digitaldesign.volkswagen-group.com/r/vyVtS4595AbJzDx8SY_ZXVR4eKNJYa0rvsOcI8D8zNc) | Floating Action Buttons (FAB) are floating, buttons that highlight a primary action on the screen and make it easily accessible. |
| [Grid](https://digitaldesign.volkswagen-group.com/r/t1hAJ5J-TTEzfUq8EnhvdkfXc6FBQeeOnwNfTHSgic4) | Grids are layout structures that organise content into rows and columns, providing a consistent and responsive framework for aligning elements within a user interface. |
| [Headline](https://digitaldesign.volkswagen-group.com/r/tmvjukwH8yFEV3B-jZiRTDBORbmXYX2hvmoZxH_G2AI) | Headlines are typographic elements used to create clear, hierarchical titles that enhance readability and structure within a user interface. |
| [Loading](https://digitaldesign.volkswagen-group.com/r/ZXx_sNRagncHArPFLj_G5d--YxkHTavkda1oOIBPVQA) | Loading components are animated indicators used to show that a process or data retrieval is in progress. |
| [Icon](https://digitaldesign.volkswagen-group.com/r/rql95hxZBSlxJgl_L-RksDhIJ8HFoIj7naVeVs4c2po) | Icons are small graphical representations used to visually convey actions, objects, or concepts within a user interface. |
| [Input](https://digitaldesign.volkswagen-group.com/r/ZsCt7yxmOTnGT7EpF5HLs7iWoa89xOFFzbBoG6agKYk) | Inputs are fields where users can enter and edit text, commonly used for forms and data entry within a user interface. |
| [Inline Notification](https://digitaldesign.volkswagen-group.com/r/EcWka3M3YcrY1Oeo3Cv4dBg3Lbckzsc39ZxcHcKeNik) | Inline notifications are brief messages displayed within the content flow to inform users about important updates or actions without disrupting their current task. |
| [Progress](https://digitaldesign.volkswagen-group.com/r/h10dpIKcNaseT2__4RSw9XJGOrkSt6GeZqJRkliDQsc) | Progress components visually represent the completion status of a task or process, often using a bar or circle to indicate progress. |
| [Radio](https://digitaldesign.volkswagen-group.com/r/SeknXdD0aeD153dJZT3CUL3hcgMpD357tOeXzznVj-w) | Radio buttons are interactive elements that allow users to select a single option from a predefined set of mutually exclusive choices. |
| [Select](https://digitaldesign.volkswagen-group.com/r/Rn4nQwr65U17Kvb134FQWHkTychZJM4HZXSAHT6WhW0) | Selects are dropdown menus that allow users to choose a single option from a list of predefined choices. |
| [Switch](https://digitaldesign.volkswagen-group.com/r/eMNGaTfrFpk5iYqmbWzMc95APEwVPDoSDTafRLftwUw) | Switches are interactive toggles that allow users to turn a setting or feature on or off within a user interface. |
| [Table](https://digitaldesign.volkswagen-group.com/r/613JM7wJHMWE3C5tT3Pf5-nXktttpi-YhtuCxXj3Grg) | Tables organise data into rows and columns, providing a structured and easily readable format for displaying information. |
| [Tabs](https://digitaldesign.volkswagen-group.com/r/jmhjcvlQ8AMBW0AeZ2nksRq69pb2WC3TDPjFEJmAKFU) | Tabs are used to organize content into separate, easily navigable sections within the same page, allowing users to switch between different views or categories without reloading the page. |
| [Tag](https://digitaldesign.volkswagen-group.com/r/VPJY7OfX_h_TAgYFhJGQe212ShkoY6haBnOEJ31IKvg) | Tags are small, stylable elements used to categorise or label content, often featuring text and an optional close icon. |
| [Text](https://digitaldesign.volkswagen-group.com/r/lEzxY-CCOHDOjoJTpV5lls-Nofphjhe2DDtmFOIDhHk) | Text is a fundamental element used to display and style written content within a user interface. |
| [Textarea](https://digitaldesign.volkswagen-group.com/r/-SVde_JFYbpjcImEkfW7cobVnugyGE7weVthmAo3vGA) | Textareas are multi-line input fields that allow users to enter and edit larger amounts of text within a user interface. |
