# FOSS List Information

---

Although GroupUI is an internal source, the open source office demands, that our customers add the library and its dependencies to their FOSS List. In the table below you can find information about our dev dependencies per version of GroupUI.
Below that you can also find the xlsx files generated with the [FOSS-List-Filler tool](https://foss-list-filler.vwapps.run/start).
