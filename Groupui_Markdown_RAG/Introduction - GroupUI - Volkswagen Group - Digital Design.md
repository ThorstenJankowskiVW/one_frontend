## Welcome
[![](./Introduction - GroupUI - Volkswagen Group - Digital Design_files/eyJwYXRoIjoidm9sa3N3YWdlblwvZmlsZVwvZkM1UUhGRlh0ZVJQQ29LQ1Q3ZEcucG5nIn0_volkswagen_LDxcaqLLBrc_SUiecKLllzBSZOzsl4heNcPk29IzOWg)](https://groupui.frontify.com/document/1717#/general/about-groupui)
GroupUI is the design system for modular user interfaces and a development framework for designing and developing digital products within the Volkswagen Group.
It enables designers and developers to build better applications and websites using a consistent design language that feels, looks and works the same way for every Volkswagen Group product on any modern device.
