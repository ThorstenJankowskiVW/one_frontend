# Spacing

---

## Usage
Spacing is one of the most frequently used variables in design and development. In order to use this uniformly and consistently at all levels, we have developed an uniform spacing to optimise and standardize the creation process in design and development.
The spacing is used to define and use a uniform size across all break points. The following table shows all predefined spacings and their usage.
