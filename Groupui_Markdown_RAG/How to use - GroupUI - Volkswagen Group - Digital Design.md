# How to use
The following examples give a better idea on how design tokens are applied in our components in design and development.
Important!
If you use our Design Tokens, please only use the System Tokens. Only by using the system tokens can we ensure that you automatically receive all changes and that you can easily switch your application or website to the different modes and themes.

---

### Button
The button component is built with many tokens like color tokens, border tokens, or dimension tokens like spacings etc. Using system tokens allows us to map different reference tokens based on the use case like a button in light mode on different in-page-theme background colors.
\*Example simplified, a button contains more tokens

### Divider
The divider is a simple component, built with tokens you can see in this example. Depending on the use case (brand, mode, theme etc.) different reference tokens can be mapped to the system tokens.
