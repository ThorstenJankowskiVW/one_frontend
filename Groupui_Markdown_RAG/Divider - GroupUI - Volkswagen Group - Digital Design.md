# Divider

---

## Usage
Dividers can be used to separate content or sections from each other and make content easier to read for the user.

---

### Divider - Live Demo
```html
<div class="divider-live-demo container-border flex-center">
<div>
<groupui-divider></groupui-divider>
</div>
</div>

```

### Divider
Assign the g-divider class to a hr or a div.

### Variants
The divider can also be used in a dashed variant by adding the class .g-divider-dashed or on inverted background

### Vertical
The divider can also be used vertically by adding the class .g-divider-vertical.
