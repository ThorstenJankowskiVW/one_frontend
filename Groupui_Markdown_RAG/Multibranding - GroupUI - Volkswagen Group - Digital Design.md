# Multibranding

---

## Introduction
We are interested in collaborating with other Volkswagen Group brands to scale, learn, and benefit from each other to create a design system that matters.
You’ll find information about the current state of multi-brand capability as well as our technology stack below.

---

## Usage
The Volkswagen Group Design System offers brands within the Group the opportunity to set up a frontend framework for the respective brands within the GroupUI design system. The focus of multi-brand capability is on the implementation of code components.
Multibrand capability within GroupUI
The design as well as the development of the brand-specific requirements must be developed by teams within the brands in coordination with the responsible corporate design departments.

---

## Collaboration
The following requirements help us to have a common understanding and make a cooperation as seamless as possible.
#### We instead of me
Developing a unified design system means benefiting from another. This means that you have to be considerate of others and sometimes have to adapt when creating components.
#### **Dedicated Design system Team**
It’s important that each brand has its own team consisting of designers, developers, and product managers when developing another brand within our design system. They need to be able to exchange information with the person responsible for corporate design.
#### **Regular exchange**
As we share the same front-end architecture with several brands, we have to coordinate our design and development to speak a uniform language. Many components already exist, and other ones are in the pipeline. This doesn’t mean you can’t question existing things.
#### **Financing**
As the owner of this product, we are responsible for the infrastructure and a smooth process across all brands. Thanks to our experience of working together, we were able to appreciate the additional work that a cross-brand collaboration needs. In the case of intensive cooperation, costs arise for our product, which we have to settle with the collaborating brands.

---

## Code
GroupUI is a framework for multiple brands. We deliver our web components including different brand specific themes.
* The components have a common code (HTML and Javascript -> Stencil JS)
* The components are styled via themes for the respective brands (CSS classes)
* The components are also offered as wrappers for Angular and React.
* The contribution is made via PullRequest
* The code must meet the requirements of our [coding conventions](https://digitaldesign.volkswagen-group.com/r/oTAPgLkXTWnTczWGRvACZRrLrk-BCyGCLME-JzAlmvU)
Access to the source code (Github access) takes place after agreed Brand collaboration!
