# Cards

---

## Usage
Cards are containers for grouping related data while allowing flexible layouts. Each card can contain different types of media, e.g. an image, text, icons and a call to action button. Cards will usually serve as an entry point for further information on a separate page, as a form of progressive disclosure rather than presenting the full details all at once.

---

## Basic card
* available in White, Deep Space Blue, Vivid Green
* border color contrasts with background color
* no elevation (shadow)
* non-interactive

---

## Interactive Card
* only available in white
* border color contrasts with background color
* no elevation (shadow) in default state
* elevation (shadow) in hover state

---

### Interaction behaviour
| State | Elevation |
| --- | --- |
| default | 0 |
| hover | 8 |
| pressed | 0 |
All information about the elevation can be found under the following link:
