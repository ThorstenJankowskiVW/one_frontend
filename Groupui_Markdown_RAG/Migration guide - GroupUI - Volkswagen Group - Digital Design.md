# Migration guide

---

## Introduction
With the implementation of the new corporate design, we have published a new documentation and a design library. We have also implemented the new design as an additional brand for the web components.
To make it easier for you to make the switch, in the following we would like to describe how applications and websites can migrate in design and code from the old group design to the new one.
Note
The migration to the new design is of course simplified with the use of our design library and developed components. Nevertheless, we recommend that you consider each scenario in an application and website separately and take into account the guidelines of the new corporate design.

---

### Support for the old design
The old corporate design is still in place and applications are not obliged to immediately switch to the new design. In addition, we will continue to provide and support the documentation, as well as the design library and web components for the old design.
However, we will focus more on the new corporate design for new features over time. All information about the old corporate design can be found under the following link:
[﻿﻿﻿Old Design Documentation﻿](https://digitaldesign.volkswagen-group.com/hub/394)

---

## Design
In order to transfer the designs for your application or website to the new design, we have created a Figma library with all basics, components and templates, which contains the same elements from the library with the old design.
To get started, we offer you to activate the new library. After activating, you have the option of rebuilding your application or website with the library or replacing the previously used basics and components individually.
Note
Our recommendation is to rebuild your application or websites for the new corporate design and to transfer the most important pages step by step.

---

### Icons
With the new corporate design, there is also a new style for iconography. A variety of system icons from the old design can still be used in the new design. We still need time to update all the icons from the old design.
Until then, you can continue to use the icons from the old design. We will also publish our Icon Guidelines soon. An overview of all existing icons can be found under the following link:
﻿
﻿[Icon Library](https://digitaldesign.volkswagen-group.com/r/I4bbndrv5UucP_gerTOF40aX81LVWbfM_lGPMxSQas4)﻿

## Code
If your application or website only uses web components from the GroupUI, they can be changed to the new design by changing the brand from `vwag` to `vwgroup`. All custom built components that are not part of the GroupUI web components need to be transferred to the new design by the creators of these.
A description of how you can change the brand can be found under the following link:
[Change brand](https://digitaldesign.volkswagen-group.com/r/0d7DsJA-gOm2orUc8UeKCobntyt6L8AvGNA0lw8y89w)
Note
In order to transfer an application or website into the new corporate design during development, we recommend planning this in advance in the design to avoid additional work.
