# Notification

---

## Usage
Notifications are informational messages that alert the user of general occurrences within a system. We can differentiate notifications into passive and action required notifications.
#### Passive notifications
* informal
* report a system occurrence that does not require user action
* announce an event of potential interest to the user
#### Action required notifications
* require user action
* are not sparked by the user's own action
* often urgent and therefore should be intrusive
Depending on the type of information we want to deliver, we can determine the correct component to use in the interface.

---

### Interaction costs
Our users are trying to reach a certain goal while using a digital product. Less notifications means it's more likely the users will reach their goal without being disrupted. A modal for example interrupts the current user flow and should be used for high priority, requiring user action notifications only.
Link
﻿[Interaction costs definition by Nielsen Norman Group](https://www.nngroup.com/articles/interaction-cost-definition/)﻿
