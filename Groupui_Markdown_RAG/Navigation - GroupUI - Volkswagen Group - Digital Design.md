# Navigation

---

## Usage
Navigation refers to the set of user interface elements that help visitors explore and interact with a product. Effective navigation not only allows users to browse through different pages but also helps them understand the relationship between those pages.

---

## Global navigation
Global navigation represents the top-level pages of a site's structure - the pages just below the home page. These controls appear in an unchanged, consistent position on all pages of a site. Global navigation includes logo/product name, main navigation categories, utility links for global functions (eg. log-in/log-out, language selection, settings).

---

### Horizontal
Use horizontal navigation when:
* site has only 2-5 main navigation categories
* number of main navigation categories will not increase in the future
* size of content area is important
[Component](https://digitaldesign.volkswagen-group.com/r/u-jsie5U913LdVeJddoa8T0wR6_EWhEzf2ybk5qq6MI)
Global horizontal navigation

---

### Vertical
Use vertical navigation when:
* site has 5+ main navigation categories
* number of main navigation categories may increase in the future
* need to nest sub menus in global navigation eg. accordion, drill down, tree.
* size of content area is not so important
[Component](https://digitaldesign.volkswagen-group.com/r/IKUaZsReYt8H5sydO8TkMIntrufO69QJqIc7Gl09ilE)

### Global side navigation - icon only variant
Use global side icon only variant when:
* site is limited to 3-7 main navigation categories only
* number of main navigation categories will not increase in the future
* size of content area is important

## Local navigation
Local navigation is used to access lower levels in a structure, below the global navigation pages. These navigation components can be mixed and matched with global navigation components and sometimes each other.

---

### Horizontal
* Use with any global navigation.
* Supports 1 level of local navigation.

---

### Vertical
* Use with any global navigation.
* ﻿Supports 1 level of local navigation in basic form.
* ﻿Can support further levels with nested accordion/ drill down navigation.

### Vertical embedded
* Use to nest sub menus in global vertical navigation
* Supports 2-3 levels of local navigation as drill down, accordion or directory tree.

### Mega menu
* Triggered by global horizontal navigation only.
* Supports 2 levels of local navigation.

* Compatible with any global navigation

## Supporting navigation
Supporting navigation is less related to navigating down the hierarchy of the product.

---

### Popover
* Use with any global navigation.
* Use popover to display actions when directing to another page breaks the user flow. eg. log-in/log-out
[Component](https:/#)
Supporting popover navigation

---

### Breadcrumb
* Use breadcrumb when the selected level in hierarchy is not visible in the the navigation.
* The breadcrumb provides the user a path back up the hierarchy.

Supporting breadcrumb navigation

---

### Footer
* Use with any Global navigation.
* Connects pages with similar topics and content, regardless of their location in the site. Links tend to cross structural boundaries.
