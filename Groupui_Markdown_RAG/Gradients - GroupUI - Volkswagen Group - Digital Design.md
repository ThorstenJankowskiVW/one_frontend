# Gradients

---

## Usage
Inspired by fluid movement, our gradients deliver our intentionally multi-layered, responsive and directional corporate expression. The gradients are a highly flexible and remarkable design element to be used across all touch points. Solid and static color blocking should be avoided. The gradient is composed with the Moving Curve which adds a certain dynamic.
